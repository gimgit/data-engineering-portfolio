S3/Apache Iceberg Lakehouse 구축 | 뤼튼 테크놀로지스

07/2026 - Present
  • 프로젝트 개요: 핵심 채팅·캐릭터 도메인 198개 테이블(약 130억 행·8.2TB)을 BigQuery → S3 + Apache Iceberg Lakehouse 마이그레이션
  • 주요 수행 내용:
    • merge → compaction → snapshot expiration → orphan cleanup → S3 noncurrent-version expiration까지 연결한 file lifecycle 설계
    • 파일 간 key-range overlap depth를 관측해 rewrite 대상을 선별하는 maintenance 규칙 수립. 관측 기능을 Apache Iceberg procedure로 구현해 upstream PR 제출(#17504)
    • Spark-on-EKS 애플리케이션별 driver·executor를 같은 AZ에 배치하도록 scheduling을 조정해 cross-AZ shuffle 최소화
  • 성과: 사용자 bucket 재파티셔닝과 static pruning으로 대표 대형 테이블의 실행당 merge 비용 약 90% 감소
  • 기술: Apache Iceberg, Apache Spark(on EKS), Parquet, AWS(S3, Glue, Athena, EKS), Kafka Connect(CDC), BigQuery, Airflow, Python, SQL
  • 기여도: [리드] 아키텍처·운영 기준 수립, 일부 인프라 구현은 팀 내 분담
